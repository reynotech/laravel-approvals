ApprovesChanges

trait ApprovesChanges (View source)

Applied to the model that casts approvals/disapprovals on a Modification (e.g. your User model).

approve()/disapprove() are interoperable with both shapes a Modification can take: when it has no ModificationItems it is decided as a whole (legacy behavior); when it has items, every pending item is resolved atomically instead. Use approveItem()/disapproveItem() to decide a single item without touching the others.

All four return false when the vote wasn't taken or couldn't be applied: the approver isn't authorized, the change was already decided (or is an audit row), its model no longer exists, or a listener vetoed the save.
