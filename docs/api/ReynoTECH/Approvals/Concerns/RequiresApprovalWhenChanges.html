RequiresApprovalWhenChanges

trait RequiresApprovalWhenChanges (View source)

Applied to the model whose changes should go through an approval workflow.

On saving, an update is either captured as a pending Modification (when requiresApprovalWhen()/requiresApproval() says so), recorded as a full audit Modification row (the default), or saved as-is.

A pending Modification is decided as a whole by approve()/disapprove() unless the model opts into per-group decisions by overriding approvableItemGroups(): in that case each group becomes a ModificationItem that can be approved/rejected independently via approveItem()/disapproveItem().
